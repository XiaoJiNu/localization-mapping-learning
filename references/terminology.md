# 定位建图术语表

| 术语 | 简明定义 | 容易混淆之处 |
|---|---|---|
| 位姿（pose） | 坐标系的旋转和平移 | 不是单纯的位置 |
| 坐标表达 | 几何对象在某坐标系中的数值 | 换表达不等于物体运动 |
| 外参 | 两个传感器或机体坐标系之间的刚体变换 | 方向写反会造成系统性误差 |
| 内参 | 传感器内部成像或测量模型参数 | 不描述传感器间相对位姿 |
| 里程计 | 连续估计相邻或局部位姿变化 | 通常短期平滑、长期漂移 |
| `odom` | 局部连续参考系 | 不保证长期全局一致 |
| `map` | 全局一致参考系 | 全局修正时可相对 `odom` 跳变 |
| 残差 | 预测与观测之间按模型定义的差 | 符号可不同，但必须全程一致 |
| 协方差 | 状态或测量不确定性的二阶描述 | 数值小通常代表更可信，不等于误差必然小 |
| Kalman 增益 | 在预测与测量之间分配修正量 | 由不确定性决定，不是固定经验权重 |
| 可观测性 | 能否由已有测量唯一推断某个状态方向 | 有传感器输入不代表所有状态可观 |
| IMU 比力 | 加速度计测得的非重力支撑效应，表达在机体系 | 不是直接的世界系线加速度 |
| 预积分 | 在两个关键帧间汇总高频 IMU 测量 | 仍依赖偏置、重力和线性化点 |
| 前端 | 处理传感器数据并生成相对约束 | 不等同于完整 SLAM 系统 |
| 后端 | 优化状态，使所有约束尽可能一致 | 需要噪声模型和良好初值 |
| 回环检测 | 识别当前地点与历史地点相同并添加约束 | 不等同于在已有地图中找初始位姿 |
| 重定位 | 在已有地图中恢复当前全局位姿 | 可在跟踪丢失或启动时发生 |
| APE | 估计轨迹相对参考轨迹的绝对位姿误差 | 常受轨迹对齐方式影响 |
| RPE | 固定时间或距离间隔内的相对运动误差 | 更侧重局部漂移，不直接代表全局误差 |
