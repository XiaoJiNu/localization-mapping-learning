# 错误记录

本页只记录本单元中真实出现过、能够复现的错误。

## M01：仅凭名称猜变换方向

- **现象**：看到 `T_ab` 时不确定是 A 到 B，还是 B 到 A。
- **根因**：变量名没有表达统一数学约定。
- **修正**：统一写为 `{}^{A}T_B`，并在计算前补全 `{}^{A}p={}^AT_B{}^{B}p`。
- **验证**：用 B 原点 `[0,0,0,1]^T` 测试，输出应是 B 原点在 A 中的位置。
- **状态**：待第 3 天复习。

## M02：逆变换只把平移改成负号

- **现象**：把 `[R,t]` 的逆误写成 `[R^T,-t]`。
- **根因**：忽略 `t` 仍表达在 A 中。
- **修正**：从点变换方程推导出 `[R^T,-R^Tt]`。
- **验证**：选择非单位旋转，检查 `TT^{-1}=I`。
- **状态**：待代码验证。

## M03：用消息处理时间查询动态 TF

- **现象**：车辆运动时，点云出现与速度相关的偏移。
- **根因**：几何链正确，但变换与测量不在同一时刻。
- **修正**：使用消息时间戳查询或插值 TF，并记录允许的最大时间差。
- **状态**：概念已理解，待实验注入延迟。
