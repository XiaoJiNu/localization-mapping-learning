# 坐标变换速查表

## 默认约定

- 坐标轴：右—前—上（`x` 右、`y` 前、`z` 上）
- 向量：列向量
- `{}^{A}T_B`：将 B 中坐标映射到 A

## 高频公式

| 操作 | 公式 |
|---|---|
| 点变换 | `${}^{A}p={}^{A}T_B{}^{B}p` |
| 变换复合 | `${}^{A}T_C={}^{A}T_B{}^{B}T_C` |
| 齐次变换 | `T=[R\ t;\ 0\ 1]` |
| 逆变换 | `T^{-1}=[R^T\ -R^Tt;\ 0\ 1]` |
| 全局车体位姿 | `${}^{map}T_{base}={}^{map}T_{odom}{}^{odom}T_{base}` |
| 全局修正 | `${}^{map}T_{odom}={}^{map}T_{base}({}^{odom}T_{base})^{-1}` |

## 下标检查

写成一条从目标到源的链：

```text
map ← odom ← base ← sensor
```

相邻坐标系应能消去；最终只保留目标坐标系和源坐标系。

## 调试顺序

1. 明确坐标轴、单位和列/行向量约定。
2. 在每个量上标注表达坐标系。
3. 检查时间戳是否一致。
4. 用原点和三个单位轴验证旋转、平移方向。
5. 检查 `TT^{-1}≈I`。
6. 比较“逐段变换”与“一次复合变换”。

## 常见红旗

- 矩阵维度正确不代表坐标系链正确。
- 逆变换的平移通常不是 `-t`。
- 度和弧度混用会产生看似合理的错误。
- 静态外参也可能方向写反；动态 TF 还必须匹配测量时间。
