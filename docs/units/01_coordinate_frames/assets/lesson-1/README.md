# lesson-1 配图说明

本目录保存 `lesson-1.md` 使用的对比版配图。

配图方法参考 `freestylefly/awesome-gpt-image-2` 中的 `Infographic Engine / 信息图引擎`：

- 每张图只承载少量模块；
- 先确定阅读顺序，再补细节；
- 使用颜色分组、箭头、短标签和留白；
- 避免长段文字和装饰性噪声；
- 公式与符号以课程正文为准。

文件编号与课程阅读顺序一致：

1. `00_course_overview.svg`：课程全景图；
2. `01_coordinate_systems_and_same_point.svg`：同一点与多坐标系；
3. `02_rfu_point_and_vector.svg`：RFU/FLU、点与方向向量；
4. `03_rpt_and_numeric_example.svg`：`R·p+t` 与二维例子；
5. `04_rotation_and_homogeneous.svg`：旋转矩阵与齐次坐标；
6. `05_composition_and_inverse.svg`：组合与逆变换；
7. `06_relative_pose_and_localization_frames.svg`：相对位姿与定位坐标链；
8. `07_tf_time_active_passive_debug.svg`：TF、时间、主动/被动与调试。
