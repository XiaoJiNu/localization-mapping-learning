# 单元 01 会话证据

本目录保存学习者实际完成的单元预检、推导、实验、终测和复习记录。参考笔记、标准答案和仓库已有测试不能替代这里的个人证据。

## 新建一次会话

1. 复制上一级的 [`workbook.md`](../workbook.md)。
2. 使用 `YYYY-MM-DD_attempt-N.md` 命名，例如 `2026-08-24_attempt-1.md`。
3. 在开始学习前填写任务契约和原始单元预检，不要先看参考答案。
4. 在同一个文件中记录运行前预测、命令、输出、错误与修正。
5. 学习结束时填写状态、下一步和复习日期。

命令示例：

```bash
cp docs/units/01_coordinate_frames/workbook.md \
  docs/units/01_coordinate_frames/sessions/2026-08-24_attempt-1.md
```

日期和次数应替换为本次真实情况。

## 证据规则

- 保留原始错误，用“修正记录”追加结论，不覆盖最初答案。
- 每条“已完成”都应指向推导、命令输出、测验或复习记录。
- AI 的评分是辅助判断，不是能力认证；最终状态以可重复证据为准。
- 当场通过只能进入“待复习”，完成延迟复验后再判断是否“已掌握”。
- 不提交公司数据、真实项目日志、内部标定、地图、账号或其他敏感信息。

## 推荐的延迟复习文件

首次学习使用 `attempt-1`。第 1、3、7、14、30 天复习可以继续建立新的 `attempt-N` 文件，并在文件顶部链接前一次记录。这样可以观察错误是否真实消失，而不是在原文件中把历史答案修改得越来越正确。
