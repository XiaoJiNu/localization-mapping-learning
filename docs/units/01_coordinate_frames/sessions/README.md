# 单元 01 会话证据

本目录保存学习者实际完成的课程记录、推导、实验、终测和复习证据。参考笔记、标准答案和仓库已有测试不能替代个人证据。

## 新建一次会话

1. 复制上一级的[工作簿](../workbook.md)；
2. 使用 `YYYY-MM-DD_attempt-N.md` 命名；
3. 先填写“步骤 1：开始”；
4. 学习[课程正文](../lesson.md)，在同一个文件中记录理解和疑问；
5. 继续填写练习、实验、终测、费曼输出和复习安排；
6. 学习结束时写明当前状态和唯一下一步。

命令示例：

```bash
cp docs/units/01_coordinate_frames/workbook.md \
  docs/units/01_coordinate_frames/sessions/2026-08-25_attempt-1.md
```

日期和次数应替换为真实情况。

## 六步与会话文件的对应关系

| 步骤 | 在会话文件中填写什么 |
|---:|---|
| 1. 开始 | 日期、环境、目标、当前疑问和坐标约定 |
| 2. 完整学习 | 五个知识块的一句话理解、关键关系和疑问 |
| 3. 练习与推导 | 原始过程、第一处错误、修正和最终结论 |
| 4. 最小实验 | 预测、命令、输出、参数变化和故障根因 |
| 5. 统一考核 | 闭卷答案、评分和五分钟费曼输出 |
| 6. 归档复习 | 证据索引、当前状态、下一步和复习日期 |

## 证据规则

- 保留原始错误，用“修正记录”追加，不覆盖最初过程；
- 每条“已完成”都应能指向推导、命令输出、终测或复习结果；
- 不在课程学习阶段提前复制标准答案；
- AI 的评分是辅助判断，不是能力认证；
- 首次学习通过后通常进入 `待复习`，完成延迟验证后再判断是否 `已掌握`；
- 不提交公司数据、真实项目日志、内部标定、地图、账号或其他敏感信息。

## 延迟复习怎样保存

首次学习使用 `attempt-1`。第 1、3、7、14、30 天复习可以建立新的 `attempt-N` 文件，并在文件顶部链接上一次记录。

这样可以观察错误是否真正消失，而不是在同一个文件中不断修改旧答案，使历史记录看起来越来越正确。
