# 单元 01：坐标系与变换链

本页是单元 01 的学习控制面板。不要先通读所有参考答案；按照本页的 8 个阶段依次完成，并把原始回答、推导、实验输出和复盘写入自己的会话记录。

> 当前仓库状态：学习材料与最小实验已准备好；仓库作者尚未在 `sessions/` 留下本单元的个人预检、闭卷推导、终测和延迟复习证据。跟随者应维护自己的会话状态，不能继承公共仓库的完成标记。

## 核心问题

已知一个点在激光雷达坐标系中的坐标，以及激光雷达到车体、车体到里程计、里程计到地图的变换，怎样把该点正确变换到地图坐标系，并证明方向、顺序、求逆和时间选择都没有出错？

完整点变换链为：

$$
{}^{\mathrm{map}}\mathbf p =
{}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}
{}^{\mathrm{odom}}\mathbf T_{\mathrm{base}}
{}^{\mathrm{base}}\mathbf T_{\mathrm{lidar}}
{}^{\mathrm{lidar}}\mathbf p
$$

## 完成后应具备的能力

1. 区分几何对象、坐标表达、点、方向向量、坐标系和位姿。
2. 从变换记号中读出源坐标系、目标坐标系、输入和输出。
3. 正确完成点变换、变换复合和齐次刚体变换求逆。
4. 写出 `sensor → base → odom → map` 的点坐标映射链，并区分它与 TF 树父子边的画法。
5. 说明 `map`、`odom`、`base` 和传感器坐标系在定位系统中的分工。
6. 对动态变换使用测量产生时刻，而不是消息处理时刻。
7. 用手算、数值实验、故障注入和闭卷测验共同验证结论。

## 前置条件

开始前只要求：

- 会做基本矩阵乘法；
- 知道二维旋转和平移的直观含义；
- 能运行 Python 3.10 或更高版本；
- 已阅读仓库的[全局约定](../../00_learning_system/conventions.md)。

若二维旋转仍不熟悉，也可以开始本单元，但应在阶段 2 先完成[连续课程](lesson.md)中的二维数值例，不要直接背三维公式。

## 本单元的范围

本单元包含：

- 坐标表达与变换记号；
- 点和方向向量；
- 二维数值例与三维齐次变换；
- 变换复合、求逆和完整坐标链；
- TF 父子边语义、测量时间戳和基本调试方法。

本单元不展开：

- 欧拉角、四元数、李群与李代数的系统比较；
- tf2 缓存、插值和 ROS 2 工具的完整实操；
- 多传感器异频同步与点云帧内运动补偿；
- 协方差传播和状态估计。

这些内容分别在后续“旋转与刚体位姿”“传感器、时间与标定”等单元继续。这里对时间戳只建立不可违反的基本约束。

## 120 分钟执行流程

时间到后应保留当前证据和明确下一步，不通过无限追问延长某一阶段。

### 阶段 0：任务契约（5 分钟）

- **输入**：[全局约定](../../00_learning_system/conventions.md)、本页核心问题、空白[工作簿](workbook.md)。
- **动作**：复制工作簿到 `sessions/`，填写日期、仓库提交、环境、今天要解决和暂不解决的问题；闭卷复述本仓库坐标轴、列向量和左乘约定。
- **AI 角色**：学习教练。只校准范围与完成标准，不开始讲解。
- **输出**：一份带任务契约的会话记录。
- **通过**：能够明确说出本次输入、输出、坐标约定和最终需要留下的证据。
- **未通过**：缩小目标并重写契约；坐标约定不明确时不得进入下一阶段。

### 阶段 1：单元预检（10 分钟）

- **输入**：工作簿中的一道综合主问题；不打开课程、推导和答案。
- **动作**：闭卷写出完整变换链，解释乘法顺序，并标出不确定之处；必要时接受一道追问。
- **AI 角色**：严格考官。不给提示，不展开教学，只标记“正确、遗漏、错误、待验证”。
- **输出**：未经润色的原始回答和错误标签。
- **通过**：本阶段的完成标准是找到真实能力边界，而不是全部答对。
- **未通过**：没有提交推理过程时重新作答；知识错误留到阶段 2，诊断不得演变成连续授课。

### 阶段 2：针对性学习（25 分钟）

- **输入**：预检缺口、[连续课程](lesson.md)、必要的[参考笔记](notes.md)。
- **动作**：只学习当前缺口；每一节结束后合上正文，用自己的话说明问题、输入、输出、坐标系、公式和失败条件。
- **AI 角色**：教学导师。先用二维直观例子，再进入三维齐次变换；只补预检暴露的缺口。
- **输出**：工作簿中的主动回忆记录和仍未解决的问题。
- **通过**：不看正文能解释“同一几何对象为何有不同坐标”“变换为何从右向左作用”“平移为何依赖表达坐标系”。
- **未通过**：回到二维原点和单位轴例子，不通过重复通读全文解决。

### 阶段 3：闭卷推导（20 分钟）

- **输入**：工作簿的推导题；此时不要打开 `derivations.md`。
- **动作**：独立完成变换复合、齐次变换求逆和二维数值例；在每个量旁标明表达坐标系。
- **AI 角色**：推导评审。学习者提交完整尝试前不给答案；检查时只指出第一处错误，让学习者先自行修正。
- **输出**：原始推导、修改痕迹、最终推导和自检结果。
- **通过**：相邻坐标系正确衔接；逆变换平移项正确；正反变换往返一致。
- **未通过**：定位第一处错误，换一个更小的二维反例闭卷重推；完成尝试后才可打开[参考推导](derivations.md)。

### 阶段 4：最小实验（30 分钟）

- **输入**：[实验 001](../../../experiments/exp_001_transform_chain/README.md)、工作簿中的运行前预测。
- **动作**：先预测输出方向和两条路径关系，再运行实验；逐项解释两段变换、复合矩阵、两个点结果和差值；再修改一个参数并重跑。
- **AI 角色**：实验导师。区分环境错误、代码错误和概念错误，不以“程序成功退出”代替结果解释。
- **输出**：命令、环境、提交号、运行前预测、实际输出、参数变化和结论。
- **通过**：逐段与复合结果在浮点容差内一致；能解释每一项输出的坐标系和参数变化方向。
- **未通过**：依次检查变换方向、乘法顺序、点的形状、旋转合法性和时间；修正后重跑。

### 阶段 5：故障注入（10 分钟）

- **输入**：实验中的正确基线，以及实验文档给出的错序或错方向任务。
- **动作**：先预测错误症状，再故意交换复合顺序或使用反向变换，运行并比较结果；写出根因和最小修正。
- **AI 角色**：工程评审。只提供排查顺序，不直接公布故障位置。
- **输出**：一个可复现的错误案例，包括预测、现象、根因、修正和防回归方法。
- **通过**：能够用坐标系语义定位错误，而不是因为矩阵维度相同就接受结果。
- **未通过**：改用原点或单位轴作为测试点；仍不能解释时记录到 `mistakes.md`，安排延迟复验。

### 阶段 6：终测与费曼输出（15 分钟）

- **输入**：[无答案终测](quiz.md)和工作簿的费曼输出区。
- **动作**：前 10 分钟闭卷作答，后 5 分钟向“懂自动驾驶感知但不了解定位”的听众解释坐标链、`map/odom/base` 和一个常见错误。
- **AI 角色**：严格考官与外行听众。分别检查技术正确性和表达是否能被非定位专业读者理解。
- **输出**：终测答案、评分、5 分钟分享稿和一个仍不确定的问题。
- **通过**：核心链、求逆和时间题必须正确，总分不少于 80%；分享中不得混淆源坐标系和目标坐标系。
- **未通过**：只回补失败目标，至少 24 小时后换题复测；不得标记“已掌握”。提交答案后才打开[参考答案](quiz_answers.md)。

### 阶段 7：归档与复习（5 分钟）

- **输入**：本次工作簿、推导、实验、故障注入和终测结果。
- **动作**：把真实错误加入[错误记录](mistakes.md)，在本次工作簿中写自己的速查与费曼输出，再用[参考速查表](cheatsheet.md)核对遗漏；记录下一步，并安排当天以及第 1、3、7、14、30 天复习。
- **AI 角色**：证据档案员。检查每个“完成”是否都有可打开的证据，不替学习者美化原始回答。
- **输出**：会话文件、证据链接、单元状态和复习日期。
- **通过**：所有状态与证据一致；下一步是一个 30 分钟内可以开始的具体动作。
- **未通过**：保持“学习中”，补齐缺失链接和下一步，不因时间到达而把状态改为完成。

## 单元过关标准

必须同时满足以下条件：

- [ ] 闭卷写出 `lidar → base → odom → map` 的完整点变换链。
- [ ] 能从输入输出坐标系解释乘法顺序，而不只说“上下标消掉”。
- [ ] 独立推导齐次刚体变换的逆，并解释逆平移项。
- [ ] 手算与本人运行的代码结果一致。
- [ ] 验证变换与其逆的乘积在选定容差内接近单位矩阵。
- [ ] 运行一次参数变化实验，并提前判断终点变化方向。
- [ ] 复现并解释一条故意错序或错方向的变换。
- [ ] 终测达到 80%，且核心链、求逆和时间题全部正确。
- [ ] 完成 5 分钟费曼输出。
- [ ] 已安排第 1、3、7、14、30 天主动复习。

闭环判据示例如下，其中 $\varepsilon$ 是选定的浮点容差：

$$
\left\lVert\mathbf T\mathbf T^{-1}-\mathbf I\right\rVert_{\mathrm F}<\varepsilon
$$
