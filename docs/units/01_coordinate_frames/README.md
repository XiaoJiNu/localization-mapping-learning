## 本单元要解决的核心问题

已知一个点在激光雷达坐标系中的坐标，以及激光雷达到车体、车体到里程计、里程计到地图的变换，怎样把该点正确变换到地图坐标系，并证明方向、顺序、求逆和时间选择都没有出错？

完整点变换链为：

$$
{}^{\mathrm{map}}\mathbf p =
{}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}
{}^{\mathrm{odom}}\mathbf T_{\mathrm{base}}
{}^{\mathrm{base}}\mathbf T_{\mathrm{lidar}}
{}^{\mathrm{lidar}}\mathbf p
$$

## 步骤 1：开始时具体做什么

1. 将[工作簿](workbook.md)复制到 `sessions/`；
2. 文件命名为 `YYYY-MM-DD_attempt-N.md`；
3. 填写会话信息、本次目标和已有疑问；
4. 阅读[全局约定](../../00_learning_system/conventions.md)，确认：
   - 右—前—上；
   - 右手系；
   - 点使用列向量；
   - 变换左乘；
   - ${}^{A}\mathbf T_B$ 的输入是 $B$，输出是 $A$。

命令示例：

```bash
cp docs/units/01_coordinate_frames/workbook.md \
  docs/units/01_coordinate_frames/sessions/2026-08-25_attempt-1.md
```

## 步骤 2：`lesson.md` 应该怎样学

按顺序学习，不需要在目录之间来回跳：

| 课程部分 | 主要内容 | 学完后应能回答 |
|---|---|---|
| 第 1～6 节：建立二维直觉 | 几何对象与坐标表达、点和方向向量、变换记号、二维数值例 | 为什么同一个点会有不同坐标？为什么是 $\mathbf R\mathbf p+\mathbf t$？ |
| 第 7～9 节：掌握矩阵工具 | 齐次变换、变换复合、逆变换、旋转矩阵性质 | 怎样组合和求逆？为什么逆平移不是简单的 $-\mathbf t$？ |
| 第 10～12 节：接入定位系统 | `sensor/base/odom/map`、TF 父子关系、时间戳 | 激光点怎样变到地图？为什么动态变换必须使用测量时刻？ |
| 第 13～16 节：工程理解与检查 | 坐标变换与物体运动、常见错误、调试顺序、学习证据 | 结果能算出来为什么仍可能错误？怎样用最小点和单位轴检查？ |

每完成一行对应的知识块，在工作簿中写：

- 一句话理解；
- 一个最关键公式或关系；
- 一个仍不清楚的问题。

这不是考试，不要求闭卷。遇到不明白的地方，应先要求二维示意图、动画或更小的数值例，再继续后面的内容。

## 本单元包含什么

- 几何对象、坐标系与坐标表达；
- 点和方向向量；
- 旋转矩阵的几何意义与基本性质；
- 二维数值例与三维齐次变换；
- 变换组合和求逆；
- 由两个全局位姿求相对位姿；
- `sensor → base → odom → map` 完整坐标链；
- TF 父子边与点坐标映射的区别；
- 测量时间戳和基本调试方法；
- 坐标表达变化与物体真实运动的区别。

## 本单元暂不展开什么

- 欧拉角、四元数、李群与李代数的系统比较；
- tf2 缓存、插值和 ROS 2 工具的完整实操；
- 多传感器异频同步与点云帧内运动补偿；
- 协方差传播和状态估计。

这些内容放在后续单元。本单元只建立不能违反的基本坐标和时间约束。

## 完成后应具备的能力

1. 区分几何对象、坐标表达、点、方向向量、坐标系和位姿；
2. 从 ${}^{A}\mathbf T_B$ 读出输入、输出、源和目标；
3. 解释 ${}^{A}\mathbf p={}^A\mathbf R_B{}^B\mathbf p+{}^A\mathbf t_B$ 的几何来源；
4. 正确完成点变换、变换组合和齐次刚体变换求逆；
5. 根据两个全局位姿计算相对位姿；
6. 写出 `lidar → base → odom → map` 点坐标映射链；
7. 区分 TF 树父子边与点坐标计算路径；
8. 说明 `map`、`odom`、`base` 和传感器坐标系的分工；
9. 对动态变换使用测量产生时刻，而不是消息处理时刻；
10. 用原点、单位轴、正反变换和逐段/复合对比检查错误。
