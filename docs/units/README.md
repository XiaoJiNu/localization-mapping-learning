# 学习单元目录

本目录存放领域专属的课程单元。通用流程、状态和模板位于
[`docs/00_learning_system/`](../00_learning_system/)，不要在每个单元中重复维护一套
学习方法。

## 当前可执行单元

当前只有[单元 01：坐标系与变换链](01_coordinate_frames/README.md)具备完整学习入口。
第一次进入时，打开[无答案工作簿](01_coordinate_frames/workbook.md)，从“阶段 0：
任务契约”开始。课程、参考推导、测验答案和预置实验已经就绪，但个人预检、推导、
运行解释和延迟复习仍需学习者自己完成。

## 单元建立原则

- 一个单元只解决一个核心问题；
- 每个单元必须对应至少一项能力目标；
- 单元按先修依赖、诊断缺口和实际价值排序；
- 只创建近期真正会使用的单元，避免大量空目录；
- 两小时只是第一轮默认时间盒，复杂主题应拆分而不是压缩证据；
- 预置材料和程序可作为参考，但不能预先标记学习者已经完成。

## 推荐文件

新建单元时复制[学习单元模板](../templates/learning_unit.md)。按需要使用以下文件：

```text
NN_unit_name/
├── README.md
├── lesson.md
├── workbook.md
├── quiz.md
├── quiz_answers.md
├── mistakes.md
├── cheatsheet.md
└── sessions/
```

- `README.md`：单元契约、入口、顺序和验收标准；
- `lesson.md`：只补当前问题需要的连续课程或参考笔记；
- `workbook.md`：无答案的任务契约、预检、练习、实践和复盘入口；
- `quiz.md`：后测题，不附答案；
- `quiz_answers.md`：与题目分离的参考答案和评分标准；
- `mistakes.md`：本单元真实出现且可以复现的错误；
- `cheatsheet.md`：可选参考卡；学习者自己的速查与费曼输出保存在会话记录中；
- `sessions/`：学习者按日期保存的工作簿副本和延迟复习证据。

文件名可以按领域调整，但“无答案作答区”“答案分离”“个人会话证据”三种职责
必须保留。单元 01 是当前的[完整样板](01_coordinate_frames/README.md)。

不是每个领域都需要代码目录。实践证据可以是程序、案例分析、口头录音、决策文档、
图表、作品或其他可检查产物。

## 推荐使用顺序

1. 从单元 `README.md` 确认核心问题和本次产物；
2. 复制无答案工作簿，完成阶段 0 任务契约和阶段 1 单元预检；
3. 按[两小时单元闭环](../00_learning_system/unit_workflow_2h.md)学习与实践；
4. 完成后测，随后才查看参考答案；
5. 在会话副本中记录错误、个人速查和五分钟输出；
6. 使用[单次学习记录模板](../templates/session_log.md)或领域工作簿保存证据；
7. 按[复习计划](../00_learning_system/review_schedule.md)进行延迟验证。

## 状态规则

- `未开始`：尚未留下闭卷预检；
- `学习中`：已经开始，但当天证据尚未齐全；
- `待复习`：首次闭环证据齐全且达到当天阈值，等待延迟验证；
- `已掌握`：通过主动回忆、迁移任务和后续复诊。

“程序运行成功”“参考答案已阅读”和“当天测验通过”都不能单独把状态改成
`已掌握`。
