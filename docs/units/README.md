# 学习单元目录

这里是普通学习者的主要入口。你不需要先理解整个仓库，也不需要先阅读通用学习系统。

## 现在从哪里开始

当前只有[单元 01：坐标系与变换链](01_coordinate_frames/README.md)具备完整课程、练习、实验和终测。

第一次进入时只做一件事：

> 打开[单元 01 主页](01_coordinate_frames/README.md)，从“步骤 1：开始”执行。

不要直接打开答案，也不要先浏览这个目录中的所有文件。每个单元主页都会明确告诉你当前步骤需要打开哪个文件。

## 每个单元只记住三个核心文件

| 文件 | 作用 | 什么时候打开 |
|---|---|---|
| `README.md` | 单元导航：目标、顺序、文件和通过标准 | 每次开始时第一个打开 |
| `lesson.md` | 第一次学习的主教材 | 建立工作簿后，从头到尾阅读 |
| `workbook.md` | 保存自己的理解、练习、实验和终测 | 开始时复制到 `sessions/`，全程填写 |

其他文件不需要提前记忆。单元主页提示时再打开：

- `notes.md`：课程看不懂时的补充说明；
- `derivations.md`：自己完成推导后核对；
- `quiz.md`：全部课程、练习和实验完成后的正式终测；
- `quiz_answers.md`：提交终测答案后评分；
- `mistakes.md`：记录可复现错误；
- `cheatsheet.md`：完成学习后的速查参考；
- `sessions/`：保存个人学习证据。

## 每个单元统一执行六步

| 步骤 | 做什么 | 主要文件 |
|---:|---|---|
| 1. 开始 | 打开主页，复制工作簿，确认目标 | `README.md`、`workbook.md` |
| 2. 学习 | 连续学完主课程，中途只记录疑问 | `lesson.md`，必要时 `notes.md` |
| 3. 练习 | 合上课程完成推导或案例，再核对 | `workbook.md`、`derivations.md` |
| 4. 实践 | 预测、运行、改一个条件、注入一个错误 | 实验入口、`mistakes.md` |
| 5. 考核 | 最后统一闭卷终测并做费曼输出 | `quiz.md`，提交后看 `quiz_answers.md` |
| 6. 归档 | 保存证据、写下一步、安排复习 | `sessions/`、进度表、复习计划 |

详细时间安排见[两小时单元学习流程](../00_learning_system/unit_workflow_2h.md)。

## 为什么先学完再考试

整个领域开始前已经通过全局诊断确定学习顺序。进入具体单元后，默认先建立完整知识结构，再集中练习和终测，不在每个小节后反复考试。

学习过程中可以：

- 向 AI 提问；
- 要求图示、动画和更小的数值例；
- 回看刚刚学过的内容；
- 在工作簿记录不理解之处。

只有步骤 5 的 `quiz.md` 属于正式闭卷考核。

## 新建单元时怎么组织

维护者可以复制[学习单元模板](../templates/learning_unit.md)。推荐结构：

```text
NN_unit_name/
├── README.md
├── lesson.md
├── workbook.md
├── notes.md              # 可选
├── derivations.md        # 有推导时使用
├── quiz.md
├── quiz_answers.md
├── mistakes.md
├── cheatsheet.md
└── sessions/
```

新单元必须做到：

1. `README.md` 能让读者一眼知道下一步；
2. 每一步写清楚“做什么、看什么、产出什么”；
3. 课程和答案分离；
4. 工作簿不预填答案；
5. 第一次学习采用“先完整学习，再统一考核”；
6. 所有相对链接可用，并通过 `make markdown`。

## 状态规则

- `未开始`：没有个人会话记录；
- `学习中`：已经开始，但练习、实践或终测尚未完成；
- `待复习`：首次学习证据齐全并达到当天标准；
- `已掌握`：通过延迟复习、变化条件和后续综合任务验证。

程序运行成功、参考答案已阅读或当天终测通过，都不能单独把状态改成 `已掌握`。
