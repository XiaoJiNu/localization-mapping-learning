# 定位建图学习地图

本页只回答两个问题：

1. 定位建图需要学习哪些单元；
2. 应按什么顺序学习。

执行某个单元时，不需要继续研究本页，直接进入[学习单元目录](../units/README.md)。当前可执行入口是[单元 01：坐标系与变换链](../units/01_coordinate_frames/README.md)。

## 当前唯一下一步

打开[单元 01 主页](../units/01_coordinate_frames/README.md)，按六步开始：先建立工作簿，再完整学习 `lesson.md`，最后才统一终测。

## 五级能力阶梯

五级阶梯描述能力深度，十个单元描述学习内容和先后顺序。每一级都需要输出证据，不能因为“看懂了”就自动升级。

| 等级 | 本阶段应具备的能力 | 最小过关证据 |
|---|---|---|
| 1：完全新手 | 区分定位、建图、里程计和 SLAM，认识传感器、坐标系与时间戳 | 能画出一条数据流和坐标链，并解释基本术语 |
| 2：基本理解 | 理解位姿、残差、概率融合、IMU 测量和主要算法的输入输出 | 能独立完成关键手算或推导，并说明变量与假设 |
| 3：实用使用者 | 能把坐标、测量模型、里程计、滤波、SLAM 和重定位连接起来 | 能运行最小示例，解释结果、误差来源和模块关系 |
| 4：问题解决者 | 能诊断时间、标定、噪声、漂移、退化和错误约束 | 能复现故障、定位根因，并用代码或数据验证修正 |
| 5：自信的实践者 | 能根据传感器、场景、算力和精度要求完成方案取舍 | 能提交有指标、有失败分析的系统方案或项目复盘 |

第一次全局诊断表明：系统关系部分已有一定基础，线性代数、概率估计和 IMU 模型仍需要补齐。第一轮 20 小时用于补稳第 2 级、稳定第 3 级，并开始积累第 4 级证据；第 5 级必须由后续项目持续验证。

## 20 小时第一轮

20 小时由十个单元各自的首次 120 分钟学习组成。当天以及第 1、3、7、14、30 天的延迟复习另计。

这表示“第一轮学习和取证预算”，不表示 20 小时后已经完全掌握定位建图。

| 单元 | 主题 | 核心问题 | 最小产物 |
|---|---|---|---|
| 01 | [坐标系与变换链](../units/01_coordinate_frames/README.md) | 一个点如何从传感器坐标系变到地图坐标系？ | 手推一条变换链并用代码验证 |
| 02 | 旋转与刚体位姿 | 旋转矩阵、四元数和李群分别解决什么问题？ | 实现旋转转换与位姿复合 |
| 03 | 传感器、时间与标定 | 时间戳、外参和噪声怎样影响融合？ | 构造时间错位或外参错误案例 |
| 04 | 最小二乘 | 残差、雅可比和正规方程从哪里来？ | 拟合一个含噪模型并分析残差 |
| 05 | 概率与卡尔曼滤波 | 均值、协方差和增益如何表达“相信谁”？ | 实现一维 Kalman 滤波器 |
| 06 | IMU 与轮速 | IMU 预积分为何会漂移，轮速何时失真？ | 静止、直行、转弯三种仿真 |
| 07 | 局部里程计 | 连续位姿如何生成，误差如何累积？ | 跑通并评估一个里程计示例 |
| 08 | 滤波与因子图 | 状态估计的两类表达如何对应？ | 用同一问题对比滤波和优化 |
| 09 | SLAM 与全局修正 | 前端、后端和回环各修正什么？ | 绘制图优化结构并观察回环效果 |
| 10 | 重定位与系统设计 | `map`、`odom`、`base` 如何协同？ | 完成一次系统方案评审 |

## 每个单元固定执行六步

整个领域开始前做一次全局诊断，用来安排学习顺序。进入具体单元后，默认不再用频繁预检打断第一次学习，而是采用：

1. **开始**：打开单元主页，复制工作簿，确认本次目标；
2. **完整学习**：从头到尾学习 `lesson.md`，中途记录疑问；
3. **练习与推导**：合上课程，独立完成关键练习，再核对参考；
4. **最小实践**：先预测再运行，改变一个条件并注入一个错误；
5. **统一考核**：完成课程和实践后，闭卷终测并做五分钟讲解；
6. **归档复习**：保存证据、记录状态并安排延迟复习。

每一步具体打开哪些文件，见[两小时单元学习流程](unit_workflow_2h.md)；进入某个单元后，以该单元 `README.md` 的链接为准。

## 单元之间怎样推进

- 单元首次学习完成并达到当天标准后，状态进入 `待复习`；
- 可以在安排好延迟复习后开始下一单元，不必等待 30 天；
- 后续单元暴露前置缺口时，只回补对应知识，不把整个路线清零；
- 同一根因错误重复出现时，进入[错误索引](error_index.md)；
- 阶段结束后用新题进行全局复诊，再调整后续顺序。

仓库已有课程、答案和代码只是参考材料。真正的完成证据来自学习者自己的练习、实验解释、终测、错误记录和延迟复习。
