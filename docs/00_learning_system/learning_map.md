# 定位建图学习地图

本页只回答“学什么、按什么顺序学”。从零启动其他领域请使用[新领域启动手册](new_domain_bootstrap.md)，执行某个单元请进入[单元目录](../units/README.md)并遵循[两小时单元执行说明](unit_workflow_2h.md)，实际完成状态见[学习进度表](progress.md)。

面向第一次进入单元 01 的读者，当前唯一下一步是打开[学习工作簿](../units/01_coordinate_frames/workbook.md)，先完成“阶段 0：任务契约”；首次闭环达到“待复习”前不进入单元 02。

## 五级学习阶梯

五级阶梯描述能力深度，下面的十个单元描述学习内容和先后顺序。每一级都需要输出证据，不能因为“看懂了”就自动升级。

| 等级 | 本阶段应具备的能力 | 最小过关证据 |
|---|---|---|
| 1：完全新手 | 区分定位、建图、里程计和 SLAM，认识传感器、坐标系与时间戳 | 能画出一条数据流和坐标链，并解释基本术语 |
| 2：基本理解 | 理解位姿、残差、概率融合、IMU 测量和主要算法的输入输出 | 能独立完成一个关键手算或推导，并说明变量与假设 |
| 3：实用使用者 | 能把坐标、测量模型、里程计、滤波、SLAM 和重定位连接起来 | 能运行最小示例，解释结果、误差来源和模块关系 |
| 4：问题解决者 | 能诊断时间、标定、噪声、漂移、退化和错误约束 | 能复现故障、定位根因，并用代码或数据验证修正 |
| 5：自信的实践者 | 能根据传感器、场景、算力和精度要求完成方案取舍 | 能提交有指标、有失败分析的系统方案或项目复盘 |

本次诊断表明：系统关系部分已局部达到第 3 级，线性代数、概率估计和 IMU 模型仍需补齐第 1～2 级。第一轮 20 小时用于补稳第 2 级、稳定第 3 级，并开始积累第 4 级证据；第 5 级必须由后续项目持续验证。

## 20 小时第一轮

20 小时只计算十个单元各自的首次 120 分钟会话：先建立坐标、概率和传感器基础，再把知识接到里程计、融合、SLAM 与重定位上。当天稍后以及第 1、3、7、14、30 天的延迟复习另计，并可与后续单元交叉执行。因此，20 小时表示第一轮首次取证预算，不是“20 小时后已经掌握定位建图”的承诺。

| 单元 | 主题 | 核心问题 | 最小产物 |
|---|---|---|---|
| 01 | [坐标系与变换链](../units/01_coordinate_frames/README.md) | 一个点如何从传感器坐标系变到地图坐标系？ | 手推一条变换链并用代码验证 |
| 02 | 旋转与刚体位姿 | 旋转矩阵、四元数和李群分别解决什么问题？ | 实现旋转转换与位姿复合 |
| 03 | 传感器、时间与标定 | 时间戳、外参和噪声怎样影响融合？ | 构造时间错位或外参错误案例 |
| 04 | 最小二乘 | 残差、雅可比和正规方程从哪里来？ | 拟合一个含噪模型并分析残差 |
| 05 | 概率与卡尔曼滤波 | 均值、协方差和增益如何表达“相信谁”？ | 实现一维 Kalman 滤波器 |
| 06 | IMU 与轮速 | IMU 预积分为何会漂移，轮速何时失真？ | 静止、直行、转弯三种仿真 |
| 07 | 局部里程计 | 连续位姿如何生成，误差如何累积？ | 跑通并评估一个里程计示例 |
| 08 | 滤波与因子图 | 状态估计的两类表达如何对应？ | 用同一问题对比滤波和优化 |
| 09 | SLAM 与全局修正 | 前端、后端和回环各修正什么？ | 绘制图优化结构并观察回环效果 |
| 10 | 重定位与系统设计 | `map`、`odom`、`base` 如何协同？ | 完成一次系统方案评审 |

## 每个单元的固定闭环

开始新领域时的 **全局诊断** 覆盖多个模块，用来生成能力画像和决定学习顺序；下面第一步是每个单元内部的 **单元预检**，只检查当前主题，不能混为同一次考试。

0. **任务契约（定向）**：确认核心问题、对应能力、已知约定和本次产物。
1. **单元预检**：闭卷回答 3～5 个问题，保留未经修饰的原始回答。
2. **针对性学习**：只补预检暴露的概念与公式，形成最小笔记。
3. **独立练习或推导**：不看参考答案完成一个关键推导或案例，记录中间步骤。
4. **最小实践**：用小程序、公开数据或领域任务验证，并解释结果与失败条件。
5. **条件变化或故障注入**：改变一个关键条件或注入一个错误，先预测再解释结果。
6. **后测与费曼输出**：闭卷后测，并用自己的话完成速查表或五分钟讲解。
7. **归档与复习**：记录真实错误、证据链接、当前状态和下一次复习日期。

仓库已有的笔记、答案和运行结果只是参考产物。完成标准不是“看过”或“复制成功”，而是学习者能够提交自己的原始回答、推导、结果解释和错题记录，并据此画出系统、解释输入输出、写出公式、跑通代码和定位问题。
