# 错误索引

错误不是按题目收藏，而是按“可复用的根因”归类。每次复盘先判断属于哪一类，再补一个反例验证。

错误状态与单元状态分开维护：`待复现` 表示现象尚未稳定复现，`待闭卷复验` 表示
已经有修正模型但没有延迟证据，`已闭卷复验` 表示延迟后能够独立修正，`迁移已验证`
表示在变化条件或综合任务中仍能正确处理。仅仅“听懂”或看过答案不作为状态。

| ID | 类型 | 典型表现 | 修正方法 | 状态 |
|---|---|---|---|---|
| E01 | 变换方向混淆 | 把带目标帧上标、源帧下标的变换误读为从目标帧到源帧 | 先写出点在源帧中的输入表达和它在目标帧中的输出表达 | 待闭卷复验 |
| E02 | 投影只会计算 | 得到最小二乘解，却说不清残差为何正交 | 从 $\mathbf A^{\mathsf T}\mathbf r=\mathbf 0$ 连接到列空间法向量 | 待闭卷复验 |
| E03 | 概率公式记忆 | 知道方差小更可信，但权重或融合方差算错 | 使用精度 $1/\sigma^2$ 推导并做极限检查 | 待闭卷复验 |
| E04 | IMU 物理量混淆 | 把加速度计输出直接等同于世界系运动加速度 | 明确机体系、比力、重力与姿态变换 | 待闭卷复验 |
| E05 | 转弯符号混淆 | 混用向心加速度和乘员感受的“离心力” | 先画世界系向心方向，再投影到机体系 | 待闭卷复验 |
| E06 | 使用处理时间 | 用消息到达时间查 TF | 始终以测量产生时间查询或插值 | 待闭卷复验 |
| E07 | 测量直接替换状态 | GNSS 到达时让位姿跳变 | 依据不确定性完成预测—更新 | 待闭卷复验 |
| E08 | 全局修正破坏连续性 | 回环后直接修改 `base` 在 `odom` 中的局部位姿 | 保持局部位姿连续，通过调整 `odom` 到 `map` 的变换吸收全局修正 | 待闭卷复验 |

## 变换方向自检关系

E01 使用下面的输入—变换—输出关系检查方向：

$$
{}^{A}\mathbf p = {}^{A}\mathbf T_B{}^{B}\mathbf p
$$

E08 使用下面的坐标链检查局部位姿和全局校正各自承担的作用：

$$
{}^{\mathrm{map}}\mathbf T_{\mathrm{base}} =
{}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}
{}^{\mathrm{odom}}\mathbf T_{\mathrm{base}}
$$
