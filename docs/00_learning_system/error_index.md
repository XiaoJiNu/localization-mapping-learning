# 错误索引

错误不是按题目收藏，而是按“可复用的根因”归类。每次复盘先判断属于哪一类，再补一个反例验证。

| ID | 类型 | 典型表现 | 修正方法 | 状态 |
|---|---|---|---|---|
| E01 | 变换方向混淆 | 把 ${}^{A}\mathbf T_B$ 当成从 $A$ 到 $B$ | 写出输入 ${}^{B}\mathbf p$ 与输出 ${}^{A}\mathbf p$ 后再相乘 | 待复习 |
| E02 | 投影只会计算 | 得到最小二乘解，却说不清残差为何正交 | 从 $\mathbf A^{\mathsf T}\mathbf r=\mathbf 0$ 连接到列空间法向量 | 待复习 |
| E03 | 概率公式记忆 | 知道方差小更可信，但权重或融合方差算错 | 使用精度 $1/\sigma^2$ 推导并做极限检查 | 待复习 |
| E04 | IMU 物理量混淆 | 把加速度计输出直接等同于世界系运动加速度 | 明确机体系、比力、重力与姿态变换 | 待复习 |
| E05 | 转弯符号混淆 | 混用向心加速度和乘员感受的“离心力” | 先画世界系向心方向，再投影到机体系 | 待复习 |
| E06 | 使用处理时间 | 用消息到达时间查 TF | 始终以测量产生时间查询或插值 | 已理解 |
| E07 | 测量直接替换状态 | GNSS 到达时让位姿跳变 | 依据不确定性完成预测—更新 | 已理解 |
| E08 | 全局修正破坏连续性 | 回环后直接修改 ${}^{\mathrm{odom}}\mathbf T_{\mathrm{base}}$ | 保持局部连续，通过 ${}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}$ 吸收全局修正 | 已理解 |
