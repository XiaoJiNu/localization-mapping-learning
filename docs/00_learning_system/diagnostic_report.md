# 第一次诊断报告

第一次诊断不是考试排名，而是为了找到最值得投入的知识缺口。评分表示当前能否稳定地解释、推导和应用，而不只看是否听说过概念。

## 本页的职责

这是作者启动定位建图学习时形成的 **全局诊断参考产物**，用于识别跨模块能力边界并决定单元顺序。它不是单元开始前的 3～5 题预检，也不能作为其他学习者的成绩或掌握证据。

- 想查看诊断如何转化为路线：进入[学习地图](learning_map.md)；
- 想跟随仓库学习：进入[单元目录](../units/README.md)；
- 想在新领域重新执行这套流程：使用[新领域启动手册](new_domain_bootstrap.md)。

新的学习者应保留自己的闭卷原始回答，再生成自己的诊断报告和错误索引；直接阅读本页只能获得参考结论，不能替代诊断。

## 结论

优势在系统结构和工程直觉；主要短板是数学表达与传感器物理模型。学习顺序因此不是直接堆叠 SLAM 算法，而是先用坐标变换、最小二乘、概率融合和 IMU 模型夯实底层，再回到已有优势模块做系统闭环。

该结论已经转化为[第一轮学习地图](learning_map.md)。当前执行入口和完成状态分别见[单元目录](../units/README.md)与[学习进度表](progress.md)。

## 第一阶段验证目标

坐标变换部分使用下面的核心关系验收：

$$
{}^{A}\mathbf p = {}^{A}\mathbf T_B{}^{B}\mathbf p
$$

- 看到该式能立即说出输入坐标系是 $B$，输出坐标系是 $A$。
- 能从最小二乘推导“残差与列空间正交”。
- 能用精度解释一维高斯融合，并检查极端噪声情形。
- 能在静止、直行和转弯时正确预测 IMU 理想输出。
- 能依据消息时间戳、TF 和协方差定位一次融合异常。
