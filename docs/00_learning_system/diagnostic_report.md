# 第一次诊断报告

第一次诊断不是考试排名，而是为了找到最值得投入的知识缺口。评分表示当前能否稳定地解释、推导和应用，而不只看是否听说过概念。

| 模块 | 得分（10 分制） | 观察 |
|---|---:|---|
| 坐标系与变换 | 7 | 已理解 TF 链和 `map/odom/base` 分工，需强化符号与方向检查 |
| 线性代数 | 5 | 能跟随计算，残差正交与投影的几何意义不够稳定 |
| 概率统计 | 6 | 理解方差代表可信度，需从精度加权完整推导融合公式 |
| 传感器 | 6 | 知道 IMU 漂移与轮胎打滑，机体系加速度和符号容易混淆 |
| ROS 与系统 | 7 | 时间戳和 TF 查询判断正确，需补异常时序与工程诊断 |
| 滤波与优化 | 6 | 理解预测—更新思想，需连接残差、协方差、增益和目标函数 |
| 里程计 | 8 | 输入输出、连续性和累计漂移理解较好 |
| SLAM | 8 | 能说明前后端、回环和位姿图，需深入约束与优化 |
| 重定位 | 9 | 能清楚区分重定位与回环，并理解通过 ${}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}$ 修正全局位姿 |

## 结论

优势在系统结构和工程直觉；主要短板是数学表达与传感器物理模型。学习顺序因此不是直接堆叠 SLAM 算法，而是先用坐标变换、最小二乘、概率融合和 IMU 模型夯实底层，再回到已有优势模块做系统闭环。

## 第一阶段验证目标

- 看到 ${}^{A}\mathbf T_B$ 能立即说出输入和输出坐标系。
- 能从最小二乘推导“残差与列空间正交”。
- 能用精度解释一维高斯融合，并检查极端噪声情形。
- 能在静止、直行和转弯时正确预测 IMU 理想输出。
- 能依据消息时间戳、TF 和协方差定位一次融合异常。
