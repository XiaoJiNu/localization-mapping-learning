# 两小时单元学习闭环

本页给出第一轮学习的默认 120 分钟时间盒。它的作用是强迫一次学习形成完整证据，
而不是规定所有知识都能在两小时内掌握。

## 适用边界

- 两小时是本仓库第一轮每个单元的默认预算，不是普遍学习定律。
- 一个核心问题在两小时内无法形成最小证据时，应拆成两个单元。
- 已有基础的单元可以缩短，但仍要保留预检、实践、后测和复习安排。
- 当天达到阈值只记为“本次通过”；延迟复习和迁移验证完成前不记为“已掌握”。

## 120 分钟八阶段

### 阶段 0：任务契约（定向），5 分钟

只确认四件事：核心问题、对应能力、已知约定和本次产物。

输出：一句可以验收的本次目标。若目标仍是“阅读完一章”，先改写为可观察动作。

### 阶段 1：单元预检，10 分钟

不看笔记回答三至五个短问题，写出推理和信心程度。AI 只追问，不提示答案。

输出：不可覆盖的原始回答。预检不是为了获得高分，而是为了决定后面 25 分钟
真正需要补什么。

### 阶段 2：针对性学习，25 分钟

只阅读与已暴露缺口直接相关的概念、公式或案例。每个新概念都要连接到当前问题，
不因资料中出现相关名词就扩展课程范围。

输出：关键概念之间的关系，以及仍未解决的问题。

### 阶段 3：独立练习或推导，20 分钟

合上参考答案，完成一个关键推导、案例判断、操作步骤或作品草案。先独立尝试，
再与参考材料对照。

输出：学习者自己的过程、差异和修正，不能只保留最终答案。

### 阶段 4：最小实践，30 分钟

完成一项可观察结果的实践任务。形式由领域决定：

- 技术领域可以使用代码、实验或数据；
- 经济与管理领域可以使用案例、图表或决策备忘录；
- 语言领域可以使用录音、翻译或写作；
- 创作领域可以使用样稿、修改对比或作品片段。

实践前先预测结果，实践后保存输入、条件、结果和解释。运行别人已经写好的程序，
但无法解释输入和输出，不算完成本阶段。

### 阶段 5：条件变化或故障注入，10 分钟

改变一个关键条件，或故意加入一个常见错误。先预测影响，再观察结果并定位根因。

输出：原条件、变化条件、预期、实际结果和解释。这一步用于区分“记住示例”和
“能够迁移”。

### 阶段 6：后测与费曼输出，15 分钟

闭卷回答单元后测，并用自己的话完成一页速查表或五分钟讲解。后测题应测试同一
能力，但不能原样复制预检题。

输出：分数、推理、仍不确定之处和面向他人的简短解释。

### 阶段 7：归档与复习，5 分钟

更新学习记录、错误索引和进度，并安排下一次主动复习。“下一步”必须是一个
30 分钟内可以开始的具体动作。

输出：证据链接、当前状态、复习日期和唯一下一步。

## 当天通过标准

单元开始前应写出专属阈值。若尚未定义，可以使用下面的最低要求：

- 后测达到事先约定的正确率；
- 独立练习和最小实践均有过程证据；
- 能解释至少一个错误的根因；
- 条件变化后能预测或解释结果；
- 能用自己的话说明核心问题、输入、输出和限制；
- 已安排下一次复习。

缺少任一关键证据时，只能记录“部分完成”并保持“学习中”。首次闭环证据齐全且
达到当天阈值后，状态才能进入“待复习”；不能为了按时结束而标记为“已掌握”。

## 何时可以标记为掌握

“本次通过”是一个学习事件，“已掌握”是经过时间和迁移检验的状态。至少在下列
证据形成后再标记为掌握：

1. 第 1 天能闭卷重做关键练习；
2. 第 3 天能在变化条件下重跑实践并解释结果；
3. 第 7 天后测仍达到阈值；
4. 后续综合任务或复诊中能正确调用该能力；
5. 同一根因错误没有持续复发。
