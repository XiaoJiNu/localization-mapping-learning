# 学习进度

本页只回答“做到哪里、下一步是什么”。学习顺序见[学习地图](learning_map.md)，具体内容见[单元目录](../units/README.md)，每个单元的执行方法见[两小时单元执行说明](unit_workflow_2h.md)。

状态约定如下：

- `未开始`：还没有留下本单元的个人预检或会话证据；
- `学习中`：已经开始，但首次学习证据尚未齐全；
- `待复习`：已完成预检、推导、实践、后测和复盘，等待延迟验证；
- `已掌握`：已通过延迟主动回忆、条件迁移，以及复诊或后续综合任务。

第一次[全局诊断](diagnostic_report.md)只用于安排路线，不等于各单元预检已经完成。全局诊断虽然暴露了坐标变换线索，但单元 01 的本次预检仍需在工作簿中重新闭卷完成。

表中的状态记录作者在本仓库留下的证据，不自动成为跟随者的学习进度。新的学习者从个人证据全空白开始，必须独立完成任务契约、闭卷回答、推导、实验解释和复盘，再维护自己的勾选记录。

## 更新规则

- 每次学习结束只更新一行，避免把维护表格变成负担。
- 在“下一步”中填写一个 30 分钟内能开始的具体动作。
- 首次两小时学习完成后最多标记为 `待复习`，不能直接标记为 `已掌握`。
- `待复习` 的单元按照[复习计划](review_schedule.md)重新测试。
- 代码或文档产物应在对应单元中留下相对链接。
