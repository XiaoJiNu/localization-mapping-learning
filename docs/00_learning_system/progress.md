# 学习进度

本页只回答“做到哪里、下一步是什么”。学习顺序见[学习地图](learning_map.md)，具体内容见[学习单元目录](../units/README.md)，单元执行方法见[两小时单元学习流程](unit_workflow_2h.md)。

## 状态约定

- `未开始`：还没有建立本单元的个人会话记录；
- `学习中`：已经开始，但课程、练习、实验或终测尚未全部完成；
- `待复习`：首次学习证据齐全并达到当天标准，等待延迟验证；
- `已掌握`：已通过延迟主动回忆、条件变化和后续综合任务。

第一次[全局诊断](diagnostic_report.md)只用于安排学习路线，不等于某个单元已经完成。每个单元仍需要学习者自己的课程记录、练习、实验解释、终测和复习证据。

表中的状态记录仓库作者在本仓库留下的证据，不自动成为跟随者的个人进度。

## 怎样更新本表

每次学习结束只更新一行：

1. 根据真实证据更新课程、练习、实验、终测和复习状态；
2. 在“下一步”写一个 30 分钟内能开始的具体动作；
3. 首次学习证据齐全后最多更新为 `待复习`；
4. 延迟复习使用[复习计划](review_schedule.md)；
5. 代码或文档产物应链接到对应单元或 `sessions/` 会话文件。

不要因为读完课程、复制答案或运行预置程序，就把相关列标记为完成。
