# 新领域启动流程

本流程用于从零启动一个可验证的学习项目。它只在开始一个新领域时使用，普通学习者进入现有课程单元后不需要重复执行。

总体顺序是：

> 定义能力 → 全局诊断一次 → 安排单元 → 每单元先学完整再考核 → 延迟复习 → 阶段复诊

## 第一步：限定选题

先回答“为什么学、学到哪里、暂时不学什么”。

至少记录：

- 真实使用场景；
- 当前基础和已有经验；
- 第一轮时间预算；
- 可以使用的教材、工具和数据；
- 明确排除的内容；
- 隐私、版权、公司资料和公开发布边界。

输出是填写后的[领域启动模板](../templates/domain_bootstrap.md)，不是一份无限扩展的资料列表。

## 第二步：定义可验证能力

能力目标使用下面的句式：

> 能够在某个场景下，对给定输入完成一个动作，产生明确输出，并用某种证据证明。

第一轮建议保留三至七项核心能力。每项能力包含：

- 能力编号；
- 输入和输出；
- 使用场景；
- 最小证据；
- 通过阈值。

“了解”“熟悉”“系统掌握”不能单独作为能力目标，因为它们无法直接验收。

## 第三步：进行一次全局闭卷诊断

诊断题映射到能力目标，并覆盖：

- 概念辨析；
- 原理解释；
- 基础计算或操作；
- 实际应用；
- 故障诊断；
- 方案比较与取舍。

保存原始回答、推理过程、用时、信心程度和是否查资料。题目和参考答案分开保存。

这一步只在领域启动或阶段复盘时执行。它用于决定“先学什么”，不是要求每个单元、每个小节都先考试。

此阶段 AI 只担任考官。若诊断过程中开始教学，应先结束诊断并明确切换角色。

## 第四步：形成能力画像

能力画像不能只统计正确率。至少判断学习者是否：

- 知道关键事实；
- 能解释原因；
- 能独立操作；
- 能迁移到变化场景；
- 能诊断错误；
- 能让信心与真实表现基本一致。

输出已有优势、基础缺口、假掌握、高频根因、优先级和暂不处理项，并链接到原始证据。

## 第五步：拆分课程单元

根据先修依赖、诊断缺口和实际价值排序，不照搬教材章节。

每个单元只解决一个核心问题，并说明：

- 对应哪些能力；
- 需要哪些先修能力；
- 本单元包含和不包含什么；
- 哪个文件是主课程；
- 每一步打开哪个文件；
- 最小实践证据；
- 当天通过标准；
- 未通过后的补救路径。

第一轮只创建近期真正要学的单元，避免提前生成大量空目录。

## 第六步：按六步完成每个单元

本仓库默认使用[两小时单元学习流程](unit_workflow_2h.md)：

1. **开始**：打开单元主页，复制工作簿，确认目标；
2. **完整学习**：从头到尾学习 `lesson.md`，中途记录疑问，不做正式考试；
3. **练习与推导**：合上课程独立完成关键练习，再核对参考；
4. **最小实践**：先预测再运行，改变一个条件并注入一个错误；
5. **统一考核**：课程和实践完成后，闭卷终测并做费曼输出；
6. **归档复习**：保存证据、更新状态并安排延迟复习。

每个单元至少留下：

1. 课程学习记录；
2. 一项独立完成的关键练习；
3. 一项可以观察结果的实践；
4. 一个条件变化或错误注入案例；
5. 学习后的闭卷终测；
6. 错误根因与修正；
7. 五分钟费曼输出；
8. 下一次复习日期。

不再把单元预检设置为默认必经步骤。需要精细诊断某个单元时可以额外加入，但不能打断第一次完整学习，也不能让学习者在尚未接触主要内容时反复接受小测。

## 第七步：进行间隔复习

复习使用主动提取，不以重读全文作为主要动作。本仓库默认在当天、第 1、3、7、14、30 天安排复习，具体动作见[复习计划](review_schedule.md)。

若某次复习失败，只回退对应能力和错误，不必把整个单元清零。重复出现的错误进入[错误索引](error_index.md)，并附可复现反例。

## 第八步：重新诊断

复诊使用“相同能力、不同表面形式”的新题，不能只重复记忆过的原题。

至少比较：

- 正确率；
- 推理和解释质量；
- 完成速度；
- 变化条件下的迁移能力；
- 信心校准；
- 错误复发率；
- 延迟后的保持程度。

根据复诊结果决定继续下一阶段、补做某些单元或修改能力目标。

## 启动完成检查

满足以下条件，才算完成新领域启动：

- [ ] 选题范围和公开边界清楚；
- [ ] 三至七项能力都有最小证据和阈值；
- [ ] 全局诊断保留原始回答，并映射到能力；
- [ ] 能力画像以证据为依据；
- [ ] 第一批单元按依赖和优先级排序；
- [ ] 第一个单元明确标出 `README.md`、`lesson.md` 和 `workbook.md`；
- [ ] 单元主页写清六步中每一步做什么、看什么、产出什么；
- [ ] 终测题与答案分离；
- [ ] 复习与复诊日期已经安排；
- [ ] 仓库根目录能让新读者一次点击找到“现在做什么”。
