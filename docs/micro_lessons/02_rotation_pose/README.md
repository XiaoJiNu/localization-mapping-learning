# 单元 02：旋转与刚体位姿

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：二维和三维旋转应怎样表示、组合、插值并在工程中保持数值合法？
- 先修条件：完成单元 01，理解旋转矩阵、齐次变换和源/目标坐标系。
- 单元产出：一份旋转表示选型表，以及能在矩阵、欧拉角、轴角和四元数之间进行基本转换的心智模型。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
