# 单元 06：IMU 与轮式推算

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：IMU 和轮速实际测到什么，怎样从测量积分出姿态、速度和位置，又为什么必然漂移？
- 先修条件：完成单元 02、03、05，理解姿态、时间、协方差和递推估计。
- 单元产出：静止、直行、转弯三种工况的理想测量预测，以及一份偏置、重力、打滑诊断表。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
