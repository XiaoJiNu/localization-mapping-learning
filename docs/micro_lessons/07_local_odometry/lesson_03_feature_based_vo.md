## 7～8 分钟：核心讲解

### 1. 检测器寻找可重复局部结构

角点在视角和光照变化下应尽量稳定，均匀分布比单纯数量更多重要。

### 2. 描述子用于跨帧识别

它将局部图像块编码成可比较向量，但相似纹理会产生歧义。

### 3. 匹配只是假设，几何才是验证

双向匹配、比值测试降低候选，RANSAC 用极线、单应或 PnP 模型筛出共同运动内点。

### 4. 特征分布决定姿态可观性

点都集中在小区域、单平面或远处时，某些位姿方向约束弱。

## 2～3 分钟：最小练习

对“特征很多但全部在天空线附近”分析：数量看似充足，哪些运动方向可能仍然不稳定？
