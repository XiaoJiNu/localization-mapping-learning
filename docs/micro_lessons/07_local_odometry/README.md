# 单元 07：局部里程计

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：局部里程计怎样连续估计相邻时刻运动，它为什么平滑却会长期漂移？
- 先修条件：完成单元 01～06，理解位姿、时间、最小二乘、概率和 IMU/轮速。
- 单元产出：一张视觉、LiDAR、轮式和惯性里程计对比表，以及一套局部里程计评测与退化诊断流程。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
