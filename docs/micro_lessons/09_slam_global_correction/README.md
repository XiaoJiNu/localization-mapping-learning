# 单元 09：SLAM 与全局修正

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：SLAM 怎样把局部里程计、回环约束和地图表示连接起来，形成长期一致的轨迹与地图？
- 先修条件：完成单元 07～08，理解局部里程计、因子图、边缘化和可观测性。
- 单元产出：一张完整 SLAM 数据流、一个小型位姿图，以及一次错误回环故障分析。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
