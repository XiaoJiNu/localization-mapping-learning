## 7～8 分钟：核心讲解

### 1. 全历史逐帧几何匹配代价太高

先用全局描述子或词袋快速检索少量相似历史关键帧，再做精确验证。

### 2. 候选检索追求高召回

真正回环不应漏掉，但高召回往往带来更多相似假候选。

### 3. 外观会因时间和天气变化

光照、季节、视角、动态物体和传感器变化要求描述子具有一定不变性。

### 4. 重复环境导致感知混淆

停车场立柱、矿井巷道和相似路口外观近似，不能只凭相似度直接加回环。

## 2～3 分钟：最小练习

为“地下停车场相似楼层”写三种降低假候选的方法：时间/拓扑先验、语义、几何验证等。

## 工程例子

视觉词袋或全局深度描述子先找历史候选；LiDAR 可用 Scan Context 等全局扫描描述。
