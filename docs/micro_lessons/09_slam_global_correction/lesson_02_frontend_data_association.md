## 7～8 分钟：核心讲解

### 1. 前端把原始观测变成几何关系

视觉匹配、点云配准、轮速和 IMU 预积分最终都产生变量之间的残差或相对位姿约束。

### 2. 正确关联比优化器更关键

错误对应会产生结构性错误约束，后端再精确也可能得到错误地图。

### 3. 局部估计提供初值和协方差

前端通常在相邻帧或局部地图内优化，并给后端相对变换与可信度。

### 4. 关键帧控制图规模和信息

只有带来足够视差、位移、旋转或新区域的帧进入全局图。

列出视觉、LiDAR、IMU、轮速各自产生的约束对象、残差和常见错误关联。

## 工程例子

视觉前端将同一角点跨帧关联形成重投影因子；LiDAR 前端将当前帧与局部子图配准形成相对位姿因子。


## 最容易混淆的地方

> 把前端估计当无误差真值输入后端，会让错误约束过度支配图优化。
