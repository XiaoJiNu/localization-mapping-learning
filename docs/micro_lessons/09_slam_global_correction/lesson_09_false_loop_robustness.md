## 7～8 分钟：核心讲解

### 1. 错误回环把不同地点强制拉到一起

一个高权重假边可扭曲整条轨迹和地图，影响后续定位形成连锁错误。

### 2. 前端应多级验证

外观检索、局部几何、多帧一致性、拓扑/时间先验和语义共同降低假阳。

### 3. 后端可降低可疑边影响

鲁棒核、动态协方差缩放、可切换约束或最大一致子集让图优化拒绝冲突边。

### 4. 上线前要故障注入

故意添加错误回环，检查监控能否发现目标突增、局部变形和约束不一致，并支持回滚。

## 2～3 分钟：最小练习

设计一条回环从候选到入图的四级门禁，并写出后端发现冲突后如何撤销。

相似楼层被误认为回环时，拓扑楼层信息、海拔、几何布局和多帧验证可以共同拒绝。
