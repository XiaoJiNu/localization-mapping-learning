# 单元 01：坐标系与变换链

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：一个传感器点怎样在不改变物理位置的前提下，被正确表达在地图坐标系中？
- 先修条件：会读二维向量和矩阵乘法；不要求预先掌握 SLAM。
- 单元产出：一条带源、目标、时间和单位标记的 `sensor → base → odom → map` 变换链。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
