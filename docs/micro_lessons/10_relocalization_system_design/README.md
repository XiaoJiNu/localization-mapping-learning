# 单元 10：重定位与综合系统设计

## 10 课 × 每课约 12 分钟 = 120 分钟

- 核心问题：系统丢失或启动时，怎样在已有地图中恢复可信位姿，并把它安全接回局部定位链？
- 先修条件：完成单元 01～09，理解坐标链、局部里程计、因子图、SLAM 和地图表示。
- 单元产出：一套面向自动驾驶、机器人或无人机的重定位方案，包括候选检索、几何验证、置信度、恢复和地图维护。

本目录参考 `microeconomicsLearning` 的日课结构，把原来的 2 小时课程拆成 10 个连续微课。每一课只解决一个核心问题，采用“先想一想 → 核心讲解 → 最小练习 → 工程例子 → 无稿复述”的固定节奏。
