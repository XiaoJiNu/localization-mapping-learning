## 7～8 分钟：核心讲解

### 1. 状态是对未来有用的最小变量集合

常见状态含位置、速度、姿态和传感器偏置。状态选得过少无法描述系统，过多则增加不可观和计算负担。

### 2. 状态模型描述理想演化

恒速模型用上一时刻位置和速度预测下一位置，控制输入可包含加速度、转角或轮速。

### 3. 过程噪声承认模型不完美

真实车辆会加速、打滑和受未建模扰动。过程噪声协方差决定预测不确定性增长速度。

### 4. 时间间隔影响传播

同一加速度噪声在更长时间间隔内会造成更大速度和位置不确定性。

## 工程例子

用恒速模型预测 100 ms 后位置。若道路颠簸或驾驶激烈，应增大过程噪声，否则滤波器会过度相信错误模型。
