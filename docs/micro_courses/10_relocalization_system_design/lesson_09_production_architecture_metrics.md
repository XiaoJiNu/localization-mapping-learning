## 1 分钟：主动回忆

离线数据集上 Top-1 召回率很高，是否足以说明系统可以量产？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

量产架构除模型/匹配器外，还包括：

```text
传感器健康与时间同步
→ 正常定位质量监控
→ 候选检索服务
→ 地图分片与版本管理
→ metric 几何验证
→ 置信度与多假设
→ 恢复状态机
→ map-odom 接入
→ 安全降级
→ 日志回传与数据闭环
```

指标至少分五层：

- 检索：Recall@K、候选延迟、内存；
- 位姿：位置/姿态误差、协方差校准；
- 决策：正确接受率、错误接受率、拒绝率；
- 恢复：成功率、恢复时间、行驶距离；
- 系统：CPU/GPU、峰值内存、地图加载、线程阻塞、安全事件。

错误接受通常比拒绝更危险，应单独约束极低概率。测试需覆盖地图过期、传感器缺失、网络不可用、重启、跨版本和长尾天气。

每次失败片段应保存可公开/合规的最小证据：输入摘要、候选、几何指标、状态转换和接入结果。

## 3 分钟：最小练习

写一份重定位量产验收表，至少包含 12 个指标，并把它们分成检索、位姿、决策、恢复和资源五组。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
