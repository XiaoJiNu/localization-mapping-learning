## 1 分钟：主动回忆

定位质量突然下降时，系统是否应立即停止全部功能并从全地图暴力搜索？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

恢复应由状态机管理，而不是单次匹配结果驱动。一个示例：

```text
TRACKING
→ DEGRADED
→ LOST
→ SEARCHING
→ CANDIDATE
→ VERIFYING
→ RECOVERING
→ TRACKING
```

每个状态定义：

- 进入/退出条件；
- 允许的传感器与搜索范围；
- 输出位姿语义和协方差；
- 车辆速度/控制限制；
- 超时、回退和人工接管；
- 日志与指标。

`DEGRADED` 可扩大局部搜索并降速；`LOST` 停止依赖全局地图的高风险动作；`CANDIDATE` 保留多假设；`RECOVERING` 需连续多帧验证并监控接入残差。

状态转换要有滞回，避免质量指标在阈值附近来回抖动。恢复失败不能无限重试占满算力，应有资源预算和安全终态。

## 3 分钟：最小练习

为上述八个状态各写一个最核心的进入条件和车辆动作。重点说明 `CANDIDATE` 为什么不能直接等同于 `TRACKING`。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
