## 7 分钟：本课微课程

三个概念使用相似匹配技术，但系统角色不同：

- **定位**：已有当前位姿先验，持续估计 \({}^{map}\mathbf T_{base}\)；
- **重定位**：先验很弱或跟踪已丢失，需要从较大范围恢复位姿；
- **回环检测**：SLAM 判断当前关键帧与历史关键帧是同一地点，为图优化添加约束。

重定位的搜索空间更大、感知混淆风险更高，因此必须有更严格的几何验证和置信度。定位失败不应立即把任意匹配当作新位姿；系统要区分：

```text
正常跟踪 → 弱跟踪 → 丢失 → 搜索候选
→ 几何确认 → 位姿接入 → 恢复稳定
```

回环通常修正地图/轨迹；重定位主要恢复当前机器人与已有地图的关系。二者都可能更新 `map→odom`，但触发条件和安全后果不同。
