## 7 分钟：本课微课程

异频传感器不会天然同时采样。常见策略包括：

1. **最近邻**：实现简单，但时间误差上限约为参考周期的一半；
2. **插值状态**：把高频位姿插值到测量时刻；
3. **积分测量**：如将两帧之间的 IMU 积分成相对运动；
4. **时间窗口**：允许多帧进入一个优化窗口，各自保留原始时间；
5. **硬件触发**：从源头降低相对时间不确定性。

对几何融合，核心不是把消息“凑成一组”，而是让所有观测对应到同一状态或明确的连续时间轨迹。最近邻误差可粗略估计为：

\[
\|\Delta\mathbf p\|\approx \|\mathbf v\|\,|\Delta t|
\]

旋转误差近似为 \(\|\boldsymbol\omega\||\Delta t|\)。

选择策略时要看传感器频率、车辆速度、允许误差、是否有可靠高频运动估计，以及算法能否处理异步因子。
