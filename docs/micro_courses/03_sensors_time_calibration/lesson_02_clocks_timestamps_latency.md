## 7 分钟：本课微课程

传感器链路中常见多个时间：

```text
物理采样/曝光
→ 传感器打时间戳
→ 总线传输
→ 驱动接收
→ 中间件发布
→ 算法开始处理
```

**时间戳**应尽量描述测量发生的物理时刻；**延迟**是从测量发生到某阶段可见的时间差；**时钟偏移**是两个时钟原点不同；**时钟漂移**是两个时钟频率略有差异。

若传感器时钟 \(t_s\) 与系统时钟 \(t_r\) 近似满足：

\[
t_r=a\,t_s+b
\]

则 \(b\) 是偏移，\(a-1\) 反映频率误差。只校正一次偏移而忽略漂移，长时间运行仍会逐渐错位。

单调时钟适合计算间隔，UTC/GNSS/PTP 时间适合跨设备对齐。系统要保留原始硬件时间，并记录转换到统一时间基准的映射及其不确定性。
