## 7 分钟：本课微课程

时间偏移、外参误差和噪声可能产生相似残差，需要使用有辨识力的实验：

```text
先静态 → 再直行 → 再转弯 → 再加减速
```

推荐顺序：

1. 核对轴向、单位、frame id 和标定版本；
2. 静态检查内外参，排除固定几何错误；
3. 查看原始硬件时间、时钟映射和队列延迟；
4. 按速度、角速度、距离对残差分桶；
5. 扫描候选时间偏移，观察动态残差最低点；
6. 固定时间后再优化外参，避免两者相互吸收；
7. 使用独立数据和闭环关系验证；
8. 注入已知 \(+\Delta t\) 或小角度误差，确认监控能识别。

典型模式：固定空间偏移常指向外参；误差与速度/角速度相关常指向时间；散布增大但均值稳定常指向噪声；少数巨大跳变常指向离群值。

诊断报告必须保留原始时间、变换链、中间投影和分桶指标，而不只保存最终图。

## 3 分钟：最小练习

构造一个对照实验：同一数据分别使用正确时间、加 50 ms 时间偏移、增加 1° yaw 外参误差。预测三种情况下静态、直行和转弯残差会怎样变化。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
