## 7 分钟：本课微课程

位姿图节点为关键帧位姿 \(\mathbf T_i\)，边为测得的相对位姿 \(\mathbf Z_{ij}\)。预测相对位姿：

\[
\hat{\mathbf Z}_{ij}
=\mathbf T_i^{-1}\mathbf T_j
\]

在李群上可定义残差：

\[
\mathbf r_{ij}
=
\operatorname{Log}
\left(
\mathbf Z_{ij}^{-1}
\mathbf T_i^{-1}\mathbf T_j
\right)
\]

总目标：

\[
\min_{\{\mathbf T_i\}}
\sum_{(i,j)}
\|\mathbf r_{ij}\|_{\boldsymbol\Omega_{ij}}^2
\]

\(\boldsymbol\Omega_{ij}\) 是信息矩阵。相邻边来自里程计，长距离边来自回环或 GNSS/地图约束。

关键帧压缩状态规模，同时保留主要运动与观测。边的协方差不能随意设置；过强错误回环会扭曲整图，过弱则无法纠正漂移。
