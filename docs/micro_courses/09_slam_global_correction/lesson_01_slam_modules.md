## 7 分钟：本课微课程

SLAM 同时估计机器人轨迹与环境地图。典型模块：

```text
传感器
→ 前端里程计/数据关联
→ 关键帧与局部地图
→ 回环候选与几何验证
→ 后端图优化
→ 全局一致地图与定位接口
```

前端提供高频局部相对运动，要求连续；后端利用更长时间跨度的约束减少累计漂移；地图保存可用于后续匹配、规划或重定位的环境表示。

里程计只使用局部观测时不可避免地漂移。SLAM 通过闭环约束让“再次看到同一地点”成为全局信息。但 SLAM 也不是自动拥有绝对地理坐标；若无 GNSS/先验，整张图仍有任意原点和朝向。

系统还需管理地图生命周期、动态物体、版本和重定位。只有一条优化后的轨迹而没有地图接口、质量状态和故障恢复，仍不是完整工程系统。
