## 1 分钟：主动回忆

## 7 分钟：本课微课程

回环候选检索的目标是在大规模历史中快速找出少量“可能是同一地点”的关键帧。方法包括：

- 视觉词袋、全局图像描述子；
- Scan Context 等点云全局描述子；
- 拓扑邻接与时序先验；
- GNSS 或粗位姿范围筛选；
- 学习式地点识别。

检索通常输出相似度和 Top-K 候选，不直接输出可信六自由度约束。它强调召回率：真正回环应尽量进入候选，但候选中允许存在假阳性，后续由几何验证过滤。

还要排除时间上太近的帧，避免把普通相邻观测当回环。重复走廊、相似路口、季节/光照变化会造成感知混淆；视角变化和遮挡会造成漏检。

评估检索应看 precision-recall、Recall@K、候选延迟与内存，而不是只展示几个成功案例。

## 3 分钟：最小练习

为视觉或激光地点识别设计候选策略：时间排除窗口、Top-K、相似度阈值和粗位置门限。解释提高召回率会怎样影响后端验证负担。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
