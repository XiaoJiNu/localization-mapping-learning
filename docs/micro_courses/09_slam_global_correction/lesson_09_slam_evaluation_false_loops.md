## 1 分钟：主动回忆

一个系统平均 ATE 很低，但偶尔发生一次错误回环导致地图折叠，能否称为可靠？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

SLAM 评估至少包含：

1. **轨迹**：ATE、RPE、漂移、闭环误差；
2. **回环**：候选召回、几何确认精度、错误回环率、确认延迟；
3. **地图**：重影、平面厚度、占据一致性、完整度；
4. **系统**：实时率、内存、重建耗时、地图规模；
5. **鲁棒性**：丢失、恢复、重置、错误回环隔离。

错误回环属于低频高损害事件，平均指标容易掩盖。必须单独统计零容忍或极低容忍指标，并保存每次回环加入前后的图变化。

测试场景应包含重复结构、反向视角、昼夜/季节、动态人车、长时间无回环和地图变化。还应注入假回环，确认开关约束、回滚和报警有效。

## 3 分钟：最小练习

设计一个 SLAM 验收表，除平均 ATE 外，至少加入 95/99 百分位、错误回环率、地图重影、恢复时间和最大资源占用。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
