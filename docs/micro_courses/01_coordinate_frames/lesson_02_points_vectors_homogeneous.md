# U01-L02：点、方向向量与齐次坐标有何区别？

## 1 分钟：主动回忆

一辆车整体向右平移 3 米。车上两点连成的箭头方向会不会因为这次平移而改变？为什么？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

点表示“在哪里”，方向向量表示“朝哪边、长度多少”。点的位置依赖坐标系原点，因此原点改变时会出现平移项；方向向量可由两个点相减得到：

\[
\mathbf v=\mathbf p_2-\mathbf p_1
\]

若两点同时平移 \(\mathbf t\)：

\[
(\mathbf p_2+\mathbf t)-(\mathbf p_1+\mathbf t)
=\mathbf p_2-\mathbf p_1
\]

平移抵消，所以从坐标系 \(B\) 转到 \(A\) 时：

\[
{}^{A}\mathbf p
={}^A\mathbf R_B{}^B\mathbf p+{}^A\mathbf t_B
\]

\[
{}^{A}\mathbf v
={}^A\mathbf R_B{}^B\mathbf v
\]

齐次坐标把两种对象统一到一个矩阵运算中。三维点写为 \([x,y,z,1]^{\mathsf T}\)，方向写为 \([v_x,v_y,v_z,0]^{\mathsf T}\)。矩阵最后一列的平移乘以 1 时作用于点，乘以 0 时自动消失。

工程上，法向量、速度方向、坐标轴单位向量不能当成点去加平移；传感器安装位置、路标位置则是点。

## 3 分钟：最小练习

给定平移 \(\mathbf t=[3,1]^{\mathsf T}\)，判断下列对象变换时是否应加平移，并说明理由：

1. 激光点位置；
2. 车头朝向单位向量；
3. 平面法向量；
4. 相机光心位置。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
