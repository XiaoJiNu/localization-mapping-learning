# U07-L02：数据关联为什么是里程计的核心难点？

## 1 分钟：主动回忆

两帧点云中有很多相似墙面，算法怎样知道当前点对应上一帧的哪一处？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

运动估计需要把不同时间的观测关联到同一物理结构。关联形式包括：

- 图像特征点匹配；
- 光流跟踪；
- 点云最近邻；
- 点到平面关联；
- 直接法中的像素亮度对应；
- 语义目标或线面特征对应。

关联通常依赖当前运动预测限制搜索范围。若初始位姿太差，最近邻可能落到错误结构；错误关联又会拉偏位姿，形成正反馈。

关联质量可由距离、描述子相似度、法向夹角、重投影误差、时间一致性和互相最近邻等检查。动态物体不满足静态世界假设，应剔除、降权或单独建模。

“匹配数量多”不等于约束好。大量点若都来自同一平面，仍可能退化；少量空间分布良好的匹配反而更有信息。

## 3 分钟：最小练习

设计两帧走廊点云的关联门限，至少考虑距离、法向、运动预测和互相最近邻。说明门限过松与过紧各会造成什么。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。

## 1 分钟：合上资料复述

解释数据关联为何与初值互相依赖，并区分“匹配多”和“几何约束充分”。

第一次卡住的位置就是下一次复习的入口，不要用重新通读整篇来掩盖卡点。
