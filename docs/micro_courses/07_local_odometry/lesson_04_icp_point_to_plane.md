## 7 分钟：本课微课程

ICP 的基本循环：

```text
当前位姿预测
→ 变换源点云
→ 查找目标对应
→ 构造残差
→ 求位姿增量
→ 重复
```

点到平面残差为：

\[
r_i=
\mathbf n_i^{\mathsf T}
(\mathbf R\mathbf q_i+\mathbf t-\mathbf p_i)
\]

它只惩罚沿目标表面法向的距离。对局部平面，切向滑动对几何表面一致性影响小，因此点到平面模型更贴合局部结构，常有更快局部收敛。

但它依赖可靠法向，且单一平面无法约束所有六自由度。外点、动态物体和错误最近邻仍会破坏结果。

ICP 是局部优化，需要足够接近的初值。多分辨率、运动预测和关键帧地图可扩大收敛域，但不能保证全局正确。
