## 7 分钟：本课微课程

全状态 EKF 直接把状态均值作为滤波变量。误差状态 EKF 维护：

- 名义状态 \(\hat{\mathbf x}\)，用非线性方程传播；
- 小误差 \(\delta\mathbf x\)，在局部欧式空间中线性化；
- 误差协方差 \(\mathbf P\)。

测量更新先得到 \(\delta\mathbf x\)，再注入名义状态。例如姿态：

\[
\mathbf R^+
=\operatorname{Exp}(\delta\boldsymbol\theta^\wedge)\mathbf R^-
\]

注入后把误差均值重置为零，并对协方差执行相应复位雅可比。

优势是旋转约束天然保持，线性化围绕小误差更合理，也便于定义 IMU 偏置等状态。代价是实现约定更复杂：左/右误差、误差坐标系、注入顺序和复位必须一致。

“误差为零”不表示真实无误差，而是误差均值已吸收到名义状态，剩余不确定性仍在协方差中。
