## 1 分钟：主动回忆

低算力控制器需要 200 Hz 状态，而回环会晚几秒到达。是否只能在 EKF 和因子图中二选一？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

两类方法的典型权衡：

| 维度 | 滤波 | 滑窗/因子图 |
|---|---|---|
| 输出 | 当前状态递推 | 窗口或全局状态 |
| 历史重线性化 | 通常不能 | 可以 |
| 延迟测量 | 处理复杂 | 自然加入相应节点 |
| 计算/内存 | 通常较固定 | 随窗口与图结构变化 |
| 实现风险 | 协方差与相关性 | 边缘化、稀疏求解、图管理 |

实际系统常组合使用：高频 IMU 传播提供低延迟状态，滑窗优化周期性校正局部状态，位姿图承担回环和全局修正。

选型步骤：

1. 明确所需输出频率与最大延迟；
2. 明确是否需要修正历史；
3. 列出异步/延迟约束；
4. 评估状态维度和窗口规模；
5. 分析可观性与相关性；
6. 设计故障恢复和资源上限。

不要把“图优化一定更准”或“EKF 一定更实时”当作无条件结论。

## 3 分钟：最小练习

对“IMU 200 Hz + 相机 20 Hz + GPS 5 Hz + 偶发回环”的系统，提出一套混合架构，标出每层频率、状态、输入输出和修正接口。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
