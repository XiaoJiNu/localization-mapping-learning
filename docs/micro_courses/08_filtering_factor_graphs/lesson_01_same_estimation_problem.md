## 1 分钟：主动回忆

EKF 和因子图一个递推、一个优化，它们是否使用完全不同的信息？

先写下或说出当前答案，再继续阅读。这里不是正式考试；目的是让新知识连接到已经学过的内容。

## 7 分钟：本课微课程

两类方法都在估计隐藏状态 \(\mathbf x\)，并使用：

- 运动/过程模型 \(p(\mathbf x_k\mid\mathbf x_{k-1})\)；
- 测量模型 \(p(\mathbf z_k\mid\mathbf x_k)\)；
- 先验 \(p(\mathbf x_0)\)。

滤波关注当前后验：

\[
p(\mathbf x_k\mid\mathbf z_{1:k})
\]

平滑或因子图关注一段轨迹：

\[
p(\mathbf x_{0:k}\mid\mathbf z_{1:k})
\]

高斯线性条件下，卡尔曼滤波与批量最小二乘可得到等价均值；差异主要在信息组织、线性化、计算方式和是否保留历史状态。

统一理解方式是：

```text
状态节点 + 约束关系 + 不确定性
```

滤波把过去压缩到当前均值与协方差；因子图显式保留窗口或全局节点与因子。选择方法前先定义问题，而不是先选“EKF”或“图优化”标签。

## 3 分钟：最小练习

为“IMU 预测 + GPS 位置测量”分别画滤波数据流和两节点因子图。标出两者共享的状态、运动约束、测量约束和噪声。

不要只在脑中判断。至少写下一行推理、一个公式、一个草图或一组输入输出。
