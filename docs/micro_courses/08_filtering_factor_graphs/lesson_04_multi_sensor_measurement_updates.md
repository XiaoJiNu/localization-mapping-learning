## 7 分钟：本课微课程

滤波器可以按时间顺序处理异步测量：

```text
IMU 传播到 t1
→ 轮速更新
→ IMU 传播到 t2
→ GPS 更新
```

每次更新都使用测量自己的时间戳。若延迟测量对应过去时刻，简单在“当前状态”上更新会产生时间错误。处理方式包括：

- 缓存历史状态并回滚重放；
- 固定延迟状态/滑窗；
- 将延迟作为状态估计；
- 超过时限时丢弃并显式统计。

还要防止重复信息。例如视觉里程计已融合同一 IMU，再把其输出与原始 IMU 当独立测量融合，会产生相关性和过度自信。模块化系统必须记录每条输出用了哪些源数据。

滤波更新顺序在线性独立高斯情形下可等价，非线性线性化和相关性会使实际顺序有影响。
