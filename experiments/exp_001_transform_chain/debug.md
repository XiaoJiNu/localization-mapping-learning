# 调试记录：坐标变换链

本页是实验参考排查表，不是学习者已经完成调试的证据。真实的预测、错误输出、修正和重跑结果应保存在单元 `sessions/` 中。

## 参考基线当前状态

- [x] 仓库代码中的源坐标系与目标坐标系约定已统一。
- [x] 逐段变换与一次复合在浮点容差内一致。
- [x] 单点使用 `(3,)`，点集使用 `(N, 3)`。
- [x] 自动测试包含刚体变换的双向求逆闭环。

这些勾选描述仓库基线，不代表当前学习者已经亲自预测、运行和解释。

## 固定排查顺序

结果不一致时按以下顺序执行，不随机交换矩阵：

1. 写出每个矩阵的源坐标系和目标坐标系，不使用含糊的 `T1`、`T2`。
2. 写出完整点变换等式，检查每一段的输入是否等于前一段输出。
3. 检查正确复合关系：

$$
{}^{\mathrm{map}}\mathbf T_{\mathrm{odom}}
{}^{\mathrm{odom}}\mathbf T_{\mathrm{base}}=
{}^{\mathrm{map}}\mathbf T_{\mathrm{base}}
$$

4. 检查代码采用的点形状；点集虽按行存储，接口内部仍与列向量公式等价。
5. 检查旋转矩阵是否正交，行列式是否接近 $+1$。
6. 用源坐标系原点检查平移。
7. 用三个单位轴检查旋转方向。
8. 检查变换与逆的双向乘积是否接近单位矩阵。
9. 比较逐段变换与一次复合变换。
10. 若涉及动态 TF，核对测量产生时间与变换时间。

## 故障 A：交换乘法顺序

### 预期特征

- 两个齐次矩阵维度相同，程序可能不报异常；
- 得到的矩阵仍可能通过“最后一行为 `[0,0,0,1]`”等结构检查；
- 但中间坐标系无法按定义衔接，结果没有声明的源到目标语义；
- 使用原点和单位轴通常比随机点更容易说明错误。

### 必须记录

- 错误表达式；
- 哪两个相邻坐标系不匹配；
- 基线与故障输出；
- 为什么维度检查抓不到；
- 防回归方法。

## 故障 B：正向与反向混用

### 预期特征

- 逆矩阵本身仍是合法刚体变换；
- 把属于错误坐标系的点输入该矩阵时，库通常无法从裸数组判断语义；
- 平移和旋转都会按错误方向作用；
- 正向再反向的往返测试可以验证一对变换，但不能替代输入坐标系检查。

### 必须记录

- 正向和反向各自的输入、输出；
- 当前点实际属于哪个坐标系；
- 最小反例；
- 修正后的重跑结果。

## 故障 C：轴约定混用

本仓库使用右—前—上，ROS REP-103 常见车体坐标使用前—左—上。两者都可能产生合法旋转矩阵，但同一数组的物理意义不同。

排查时逐轴写出物理方向，并用单位轴完成显式转换测试。只修改帧名不能完成约定转换。

## 故障 D：时间错位

当前实验脚本使用确定性静态数值，没有模拟 TF 缓存和运动延迟。若真实系统只在运动时出现偏移，应记录：

- 测量产生时间；
- 消息接收和处理时间；
- 实际查询的 TF 时间；
- 该时间段内的平移和旋转变化。

时间错位代码实验在后续时间与标定单元完成，本单元只要求能够识别错误模型。

## 何时可以结束调试

以下条件同时满足后，才能把本次故障标记为已定位：

- [ ] 正确基线可以重复运行；
- [ ] 故障可以由单一改动稳定复现；
- [ ] 学习者能在查看输出前预测主要症状；
- [ ] 根因由坐标语义或时间证据支持；
- [ ] 修正后基线与自动测试重新通过；
- [ ] 已把错误和下一次复验写入会话记录。
